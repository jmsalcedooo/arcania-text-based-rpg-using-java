# Arcania: A Text-Based Role-Playing Game using Java

Arcania is a text-based Java RPG where a student's failing GWA transports them into the fantasy world of Eldoria to battle monsters and complete quests. Built using core object-oriented programming principles, the game features dynamic combat, custom ASCII art, and interactive mini-games like word guessing, math quizzes, and rock-paper-scissors.

[![Programming Language](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge)]()

---

## 💡 Overview & Features
* **Engaging Premise:** A relatable student story where a failing General Weighted Average (GWA) transports the protagonist into the mystical fantasy realm of Eldoria.
* **Core OOP Design:** Built leveraging fundamental object-oriented programming principles for structured, scalable game architecture.
* **Dynamic Combat & Quests:** Engage in monster battles and complete immersive narrative quests.
* **Interactive Mini-Games:** Features built-in mini-games including word guessing, math quizzes, and rock-paper-scissors to test player skills.
* **Custom ASCII Art:** Implements unique text-based visuals to enhance the retro RPG atmosphere.

---

## 🛠️ Tech Stack & Architecture
* **Programming Language:** Java
* **Paradigm:** Object-Oriented Programming (OOP)
* **Type:** Console/Text-Based Application
