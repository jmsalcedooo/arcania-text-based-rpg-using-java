# Arcania: A Text-Based Role-Playing Game (Java)

[![Programming Language](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge)]()
[![Status](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge)]()

**Arcania** is a text-based Java RPG where a student's failing General Weighted Average (GWA) transports them into the fantasy world of Eldoria to battle monsters and complete quests. Built using core object-oriented programming principles, the game features dynamic combat, custom ASCII art, and interactive mini-games like word guessing, math quizzes, and rock-paper-scissors. 

* **Main Programmer:** Hero Retuerma
* **Main Documentation & Testing:** Triscia Cabello
* **My Role:** Implementation of Hearts, Rock-Paper-Scissors, Ideation of ASCII Arts, and Sound Effects

---

## 💡 Overview & Features
* **Engaging Premise:** A relatable student story where a failing GWA transports the protagonist into the mystical fantasy realm of Eldoria.
* **Core OOP Design:** Built leveraging fundamental object-oriented programming principles for a structured, scalable game architecture.
* **Dynamic Combat & Quests:** Engage in monster battles and complete immersive narrative quests.
* **Interactive Mini-Games:** Features built-in mini-games including word guessing, math quizzes, and rock-paper-scissors to test player skills.
* **Custom ASCII Art:** Implements unique text-based visuals to enhance the retro RPG atmosphere.
